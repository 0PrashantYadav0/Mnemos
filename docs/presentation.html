The problem

Game NPCs have goldfish memory

Most game "memory" is a flag or a flat vector store. It can tell you a scene sounds similar to a past one — but it can't model who told whom, how a belief travelled, or that a rumor is second-hand and distortable.

Vector search finds similar text. It cannot represent that NPC B learned about an event from NPC A, along a specific social path.

Result: towns full of independent chatbots that don't actually feel alive.

The idea

A town where memory is the mechanic

Real memory

Every NPC genuinely remembers what you did, who told them, and how they feel about you.

Gossip spreads

Deeds propagate between characters as rumors across graph edges — reputation travels ahead of you.

Choices compound

Kindness and cruelty snowball into wildly different endings. The graph you build decides your fate.

And a "Memory Potion" that calls forget() to surgically erase an NPC's grudge — the on-theme showpiece.

The key insight

Why a graph, not vectors?

Typed nodes: Player · NPC · Event · Item · Location · Faction · Rumor · Trait

Typed edges: helped · harmed · owes-favor · trusts · distrusts · witnessed · told-about · member-of · has-trait

The star edge is told-about (NPC → NPC gossip). It encodes that a belief is second-hand, weaker per hop, and travelled a real social path — a relationship, not a similarity score.
Architecture

A fully decoupled "NPC Brain"

Web client
Phaser 3 → Game server
FastAPI → NPC Brain
4 verbs → Knowledge graph
source of truth

The game only knows four HTTP verbs — /brain/remember, /recall, /improve, /forget. Swap the client, or drop the Brain into any game; it stays untouched. That decoupling is the whole pitch.

The engine

Four verbs run everything

remember

Write an event + typed edges. Trust shifts; betrayal counts more than a favor.

recall

Blend first-hand edges, second-hand rumors, and topic search into a disposition.

improve

Derive traits, reweight, and propagate rumors to socially-connected NPCs.

forget

Surgically delete a grudge + its rumor cascade. The rest of the graph survives.

Deterministic math is the source of truth. Mirrors to Cognee Cloud when a key is present.

The magic moment

Reputation arrives before you do

# Act 1: you help Mira. She witnessed it.
brain.remember(actor=player, target=mira, deed="helped")

# improve() spreads it to Mira's district & faction...
brain.improve(scope=mira)   # told-about edges, confidence decays per hop

# Act 2: a stranger you've never met already knows.
brain.recall(subject=stranger, about=player)
#  → secondhand: "Mira speaks well of the stranger" (confidence 0.7)
#  → mood: "friendly"  (hearsay nudges trust, but weaker)

In-game, the Rumour Ticker shows those told-about dots travelling the graph in real time.

The showpiece

The Memory Potion: forget()

In Act 4 you brew a potion that does something vector memory can't do cleanly: surgically remove one grudge — the harmed and distrusts edges, the seed event, and the rumor cascade it spawned — while leaving every other memory intact.

brain.forget(target_subject=renna, target_about=player,
             edges=["harmed", "distrusts"], cascade_rumors=True)
# → disposition_after: mood flips "hostile" → "neutral"

It's the theme made mechanical: forgetting as a precise graph operation.
